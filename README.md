# lwiggy

## How to Run
### Prerequisites
1. Java 21 installed
2. Maven installed
3. Node.js (v18+) installed
4. MySQL database running

### Step 1: Run Backend
1. cd lwiggy/backend
2. ./mvnw spring-boot:run
3. Backend will start at http://localhost:8080

### Step 2: Run Frontend
1. cd lwiggy/frontend
2. npm install
3. npm run dev
4. Frontend will start at http://localhost:5173
